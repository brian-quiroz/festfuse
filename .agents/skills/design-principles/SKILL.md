# FestFuse design principles

Read and follow [the shared design principles](../../../docs/design/design-principles.md).
It defines the color semantics (cyan, yellow, celebration magenta, red, pass gray),
the festival-identity color exception, the dark visual foundation, and the visual
design principles (photography over illustration, hierarchy over density, progressive
disclosure).

Apply it to all work under `app/**/*.{tsx,css}`.
