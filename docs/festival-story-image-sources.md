# Festival Story card background image sources

Provenance for the decorative background images in `public/festivals/story/`, mapped
to card types in `app/data/festival-story.ts`. These are mood/atmosphere backdrops
behind the Festival Story cards, not artist photos (those have their own structured
provenance: see `provenance/` and the `imageCredit` fields on artist data).

All entries below are **Pexels License** (free use, modification allowed, no
attribution required, no resale of the unaltered file, no implication of endorsement).

Images added before this file existed are not individually recorded; record every
new one here as it is added.
